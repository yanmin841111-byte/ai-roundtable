# 新增 CLI / API 選擇器文案

`#ext-picker` 的最終用字。卡片名稱讀範本 JSON 的 `label`,不改 `adapters/templates/`。

| 位置 | 用字 | 備註 |
| --- | --- | --- |
| 分段切換 | **CLI**、**API**、**全部** | 與設定頁 `TYPE_LABEL`(CLI / API)一致;「全部」留給 Aider 這類 `js` 外掛 |
| 分段 `data-filter` | `cli`、`api`、`all` | 對應範本 `type`:`cli` / `openai` / 其他。預設選「全部」 |
| 搜尋框 placeholder | **搜尋名稱或說明** | 過濾範圍是名稱與描述 |
| 搜尋無結果 | **沒有符合的範本** | 次句見下方空狀態 |
| 空白範本分組標題 | **從空白開始** | 卡片名稱維持 **我的 CLI** / **我的 API**;有分組標題後語意夠清楚 |
| 品牌範本分組標題 | **現成範本** | 和空白組對仗;清單短時也保留 |
| 卡片動作提示 | **使用此範本 →** | 點擊是複製到擴充資料夾並打開編輯器,不是複製到剪貼簿 |
| 說明文字 | **點選範本即可複製到擴充資料夾並打開編輯器。** | 「沒有現成的就選空白」改由「從空白開始」分組承擔 |

## 空狀態

搜尋或分段過濾後 0 筆時,取代卡片列表:

- 主句:**沒有符合的範本**
- 次句:**試試清空搜尋,或改選「全部」。**

## 分組與排序

- 「現成範本」在上、「從空白開始」在下。空白是找不到現成項時的退路,不要置頂。
- 空白組只收 `blank-cli.json` / `blank-api.json`(或 `id` 為 `my-cli` / `my-api`)。Aider 不是空白範本,放「現成範本」,且只在「全部」可見。

## 刻意不改

- 對話框標題維持 **新增 CLI / API**
- 範本 JSON 的 `label` / `description`(含「我的 CLI」「我的 API」)維持不變
- 關閉按鈕 ✕、編輯器其餘文案不在此規格範圍

# 時間線與 Composer 附件文案

頂欄 `#phase-pill` 維持即時狀態(例如「討論 第 1/3 回合」或「閒置」)。時間線內的分隔是結構標記,不重複 pill 的逐字狀態。

| 位置 | 用字 | 備註 |
| --- | --- | --- |
| 階段吸頂 | **① 討論**、**② 分工執行**、**③ 交叉審查**、**@ 指定回覆** | 與空狀態步驟、流程選單一致。`修復` 算審查後半段,歸 ③,避免時間軸倒退。`@ 指定回覆` 只在 @ 指定開啟的任務與任務結束前補的指定回覆出現 |
| 討論回合細線 | **第 N 輪 / M** | `M` 為設定的最大討論回合;沒有設定時只寫 **第 N 輪** |
| 連續發言 | (無額外文案) | 同一成員連續訊息合併頭像,色票沿用 `--c` |
| 正在輸出 | **正在輸出…** | 出現在該則 bubble 底部狀態線;側欄對應成員頭像加亮點 |
| 迴紋針按鈕 | **附加檔案**(`title` / `aria-label`) | 圖示 📎 |
| 拖放提示 | **放開以附加檔案** | composer 進入 dragover 時覆蓋顯示 |
| 附件 chip 移除 | **移除附件** | `aria-label` 為「移除 {檔名}」 |
| 非圖片 chip | 📄 + 檔名 + 大小 | 圖片用縮圖,GIF 第一版顯示靜態首幀 |

## 附件錯誤(不靜默丟檔)

`#attach-error` 設 `role="alert"`,錯誤留到下次附加／移除／送出才清,不自動消失。一次只顯示第一個錯誤。句式統一為 **無法附加「{檔名}」:{原因}**,不可只寫「附加失敗」。上限數字以後端 `limits` 為準,預設如下:

| 情況 | 用字 |
| --- | --- |
| 超過 10 檔 | **無法附加「{檔名}」:一次最多 10 個檔案** |
| 單檔超過 20 MB | **無法附加「{檔名}」:單檔不能超過 20.0 MB** |
| 合計超過 50 MB | **無法附加「{檔名}」:這次附件合計不能超過 50.0 MB** |
| 副檔名不符 | **無法附加「{檔名}」:不支援此類型,請改傳圖片、文字檔或 PDF** |
| 內容與副檔名不符 | **無法附加「{檔名}」:內容不是 PNG 格式(副檔名與實際內容不符)**(副檔名隨檔而變;後端 magic bytes 訊息會帶上檔名) |

沒有檔名的例外(例如對話框本身失敗)才用 **無法附加檔案:{原因}**。

白名單副檔名:png / jpg / jpeg / webp / gif / txt / md / json / csv / log / pdf。有附件 IPC 時,驗證與儲存都在 main process;renderer 負責選檔、拖放,並把後端 `{ name, error }` 編成上表句式。

## 平行發言並排

執行、交叉審查、修復,以及同時 @ 多位成員時,同一批平行發言放在同一個格狀容器:每列最多三張,第四張起換行(3 張為 `000`,4 張為 `000 / 0`,6 張為 `000 / 000`)。並排時頭像移進標題列,階段徽章由上方吸頂分隔代替;只有一張時與一般訊息相同。

## @ 指定成員

| 位置 | 用字 | 備註 |
| --- | --- | --- |
| 輸入框 placeholder | **描述任務,或輸入 @ 指定成員處理…(Enter 送出,Shift+Enter 換行)** | |
| 選單標題 | **指定成員** | 輸入 `@` 或 `＠` 後出現;↑↓ 選擇,Enter / Tab 帶入,Esc 關閉 |
| 選單項目 | 頭像 + 名稱 + **{CLI} · {模型}** | 只列啟用中的成員 |
| 閒置時提示 | **@ 指定:只有 {名稱} 會回覆,不跑討論流程** | `#hint`,accent 色 |
| 進行中提示 | **@ 指定:{名稱} 會在下一次發言時看到;任務結束前沒輪到會補一次回覆** | |
| 訊息內的 @名稱 | 膠囊樣式 | 程式碼區塊內不轉換 |

## 繼續歷史對話

| 位置 | 用字 |
| --- | --- |
| 預覽視窗按鈕 | **繼續這段對話**;已是目前對話時為 **目前的對話**(停用) |
| 預覽視窗說明 | **載入後可以直接接著送出訊息,成員會先讀過這段紀錄。** |
| 進行中 | **目前仍在進行中,停止後才能載入其他對話。** |
| 已是目前對話 | **這段紀錄就是目前的對話,直接在下方輸入即可。** |
| 載入失敗 | **無法載入:{原因}** |

側欄清單中目前對話以白底、粗體標題與 accent 圓點標示。同一段對話每次任務結束都寫回同一份紀錄。

## 刻意不改(時間線)

- 不做左右分欄(平行發言的格狀並排除外)
- 頂欄 `#phase-pill` 文案格式不改
- 訊息進場只淡入位移一次;`prefers-reduced-motion` 時關閉進場、呼吸光暈與 spinner 動畫
- `focus-visible` 外框必須保留
